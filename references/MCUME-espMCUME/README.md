# MCUME / espMCUME

Referencia/linhagem do port do nucleo Atari para microcontroladores.

- https://github.com/Jean-MarcHarvengt/MCUME
- https://github.com/Jean-MarcHarvengt/espMCUME

O MCUME agrega/porta varios emuladores existentes e credita seus autores originais. HALO 2600 RETRO adapta a camada Atari/ESP para ESP32-S3, TFT_eSPI, LittleFS, Dabble, Wi-Fi e PSRAM.
